**WanderBuddy helps groups travel together.** Travellers find group trips run by real agencies and live the whole trip in one app. Agencies list their trips for free, run their business in our CRM, and pay us only when a traveller books.

This repo holds everything we have made to market it, plus what you need to make more.

## Getting the files

Click any file to download it. To get everything at once (about 4.5 GB), clone the repo with [GitHub Desktop](https://desktop.github.com): File, Clone repository.

A few long films were re-encoded to fit GitHub's 100 MB file limit. Ask us for the full-size masters.

## Five rules

1. No yellow, no em dashes, no exclamation marks, no italics.
2. One headline per frame, nothing under it.
3. AI and stock footage set a mood. They never stand in for a real trip someone can buy.
4. Only show what is live in the product today.
5. Never put agency prices in an ad. Send agencies to [a call](https://wanderbuddyapp.com/partners/call).
