WanderBuddy Cinematic Ad — asset package
=========================================

clips/    9 final animated plates in order (01–09). Silent, 1080p, 9:16. These are the deliverable.
stills/   Keyframe stills for some beats (01,02,05,06,09). The others are the first frame of their clip.
screens/  Real WanderBuddy UI, one per beat (beat01..beat09), to composite onto the phone screen (Path A).
logo/     glyph-white.png — the brand mark for the ending.
CINEMATIC_AD_COMP_MAP.md — the edit sheet: which screen per beat, how each transition is built, the ending, the music bed.

How it was made: Higgsfield soul_cinematic stills -> Kling 3.0 pro image-to-video (1080p, silent).
The phone screens in the clips are deliberately BLANK azure plates — track & replace them with the
real UI in screens/, then build the invisible transitions between beats and lay one music bed.

Order of beats: alpine -> beach(capture&share) -> tokyo -> market -> group budget-split -> train(Live
Conversation) -> desert -> rooftop(photo memories) -> dual-device logo reveal.
